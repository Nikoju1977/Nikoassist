Accueil
Votre IA travaille sur votre appareil. Aucun abonnement, aucune clé API. Au premier lancement, un modèle libre est téléchargé depuis Hugging Face. Ses calculs se font ensuite dans le navigateur. Ce mode permet le chat local, pas encore les actions JARVIS sur d'autres applications.

Sélectionnez le modèle et touchez « Charger l’IA ».

Bonjour, je suis NikoAssist

Je peux discuter, reformuler un texte et proposer des idées, sans serveur et sans clé Mistral. Le modèle léger fonctionne sur davantage d'appareils ; Qwen offre généralement de meilleurs résultats en français.

Les messages sont conservés uniquement dans ce navigateur. Vérifiez les réponses importantes : les petits modèles peuvent se tromper. Le téléchargement initial et la disponibilité hors ligne dépendent du réseau et du cache de votre navigateur.
