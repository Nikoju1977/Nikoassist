    STUDIO NIKO / GUIDE INTÉGRÉ

    Nikoassist

    Assistant web : météo, Wikipédia, calculatrice, tâches locales et dictée. Moteur Python distinct.

    Premiers pas

    1. Ouvrez l'assistant web et saisissez « Météo à Nantes », « Qui est Alice Guy ? » ou « Calcule 2+2 ».
    2. Ajoutez et cochez des tâches dans la colonne personnelle.
    3. Utilisez « Lire les réponses » ou la dictée si votre navigateur le permet.

    Avant de commencer

    Les moteurs IA et les commandes externes exigent parfois un fournisseur, des accès réseau ou une autorisation.

    Les outils web gratuits fonctionnent sans clé ; le moteur Python multi-agent n'est pas raccordé à cette interface.

    En cas de problème

    En cas de page vide ou d'erreur : rechargez une fois, vérifiez la connexion et les permissions ; sur une PWA déjà installée, fermez-la puis rouvrez-la pour actualiser son cache. Consultez le dépôt GitHub si le problème persiste.
